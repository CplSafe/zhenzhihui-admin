# 定制宣传片 T+5 后台

路由 `/promo-t5`，菜单位于 AI 任务之后。沿用现有后台身份与品牌样式，按 PRD §8 共用内部账号、文本派工，不新增制作人员注册或指派下拉。

## 页面与流程

- 列表：默认50条，单位、联系人、电话、时长、比例、分辨率、素材完成度、承诺与实际交付、制作/计费状态、逾期、提醒、修改申请独立列；状态/计费/提交日期/逾期筛选及CSV导出。类型固定「宣传片T+5」，机器任务仍从原AI任务菜单查看。
- 统计与提醒：累计发起、在制、返工、逾期、在制阈值提醒；当前责任账号的站内新单/修改/逾期提醒，可跳订单、标记已读；未提醒订单可重试。
- 详情四个标签：需求与素材、制作与交付、修改申请、操作历史。
- 素材私有预览与下载：图片/视频/音频内嵌预览，其余文件下载；临时地址可刷新，不存为永久链接。支持线下交接与人工低清标记。
- 制作：编辑「谁在做」、改期并填写原因、开始制作、直传成片及进度。失败保留文件与素材ID重试；完成检查失败不再重传正文。离开页面中止上传，上传或提交期间禁止关闭订单。
- 复核：选择已上传候选片并填写交付说明 → 待复核；可退回制作。通过二次确认后才交付与结算。交付请求绑定本次复核的素材ID，其他人更换候选片后409需重新检查。
- 退款：仅首次未交付且积分冻结订单可操作，必填原因及二次确认；终止制作并全额退回，不给已结算返工显示退款入口。
- 返工：客户意见原文、首次交付/申请截止日、受理或婉拒及处理回复。受理不收费，返工日期严格首次交付日+2自然日，不顺延。
- 历史：时间、后台/客户/系统操作人、动作与变更内容，派工变更保留前后记录。

## 权限与接口

`admin.promo.read` 控制路由、订单查看、下载与导出；`admin.promo.write` 控制制作/复核/交付/退款/返工/已读。只读账号不显示写操作。角色权限页新增中文分组，复用既有角色授权系统，后台仍为最终授权边界。

调用真实接口 `/api/v1/admin/promo` 下 `orders`、`orders/{id}`、`orders/{id}/actions`、`orders/export`、`stats`、`notices`、`notices/{id}/read`、`uploads`、`materials/{id}/retry|complete|download`。详见后端 `docs/features/promo-t5.md` 与 Swagger。

存储直传不携带业务登录信息；CSV导出使用带登录凭据的请求，并显示后台返回的失败原因。日期筛选明确使用北京时间，承诺日期从排他截止时间减去最小时间单位再格式化，避免显示成次日。

## 实现与验证

采用现有 ListPageShell、usePagedList、权限守卫和 React Query；通用分页只新增可选 initialPageSize，其他页面默认20条保持不变。共用动作提交、状态能力判断、素材预览组件和表单弹窗，避免每个动作维护一套请求/错误逻辑。

无生产模拟数据。浏览器验证由临时网络拦截提供隔离样本，不写真实客户订单或扣积分。TypeScript/生产构建、ESLint、20项单元测试，以及浏览器查看/下载、派工、开始制作、提交复核、退回/交付、上传失败重试、退款、返工受理/婉拒、只读、筛选导出与响应式检查。

真实对象存储CORS/上传下载、已配置账号和实际客户单仍需联调；未部署。客户侧T+5页面和规则配置编辑页不在此次页面接入范围，规则继续通过既有后端配置接口管理。

设计记录：使用 accent-ladder 队列/详情方向，保留现有品牌紫色与字体；首屏回答「哪些订单需要处理」，以承诺日期、逾期红标、修改待处理和双轨计费状态体现本业务；不为零/少量真实订单填充虚构图表。

最终验证使用 Node 22.22.1：`tsc -b`、`eslint .`、`node --experimental-strip-types --test tests/*.test.ts`（20/20）、`vite build` 均通过。构建保留既有大分包体积提示。设计源码检查0 FAIL；已登录DOM快照检查0 FAIL、2 WARN（现有深色侧栏色占比与全高页面少量订单的空白），保留现有品牌紫色；1440/768/390实页截图另行检查，无页面横向溢出，宽表在表格内横向滚动。


## T+5 配置入口

`/promo-t5` 的「功能配置」打开规则抽屉，调用 GET/PUT `/api/v1/admin/promo/config`。
读取沿用宣传片查看权限，保存要求 `settings.write`；无权限账号只读。
表单完整发送配置，基础单价单位为积分/秒（支持三位小数），倍率 10000 表示一倍；文件大小以字节输入并提供 GiB 对照。开放新订单前必须填正单价。
首次交付和返工按自然日；返工期限从首次交付日计算。已有订单保持后端保存的快照。
无模拟接口。前端 build、lint 和现有测试验证；真实账号浏览器验收及线上部署待进行。
